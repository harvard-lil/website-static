Data.gov Archive Search

A project of the Library Innovation Lab at Harvard Law School

This interface supports searching the Library Innovation Lab (LIL)'s archive of Data.gov datasets. The collection contains 17.9 TB of data across 311,604 datasets harvested, beginning in 2024, from public data cataloged at the "home of the U.S. government's open data."

You may also browse the entire archive on Source Cooperative. Each entry here includes links to both the objects in Source Cooperative and the original Data.gov dataset, if available. For more information, see LIL's Public Data Project.
